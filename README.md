# 楽天・Yahoo! DTF画像ツール（orimake 注文・出荷）

楽天・Yahoo!の未出荷注文CSVを読み込み、商品管理マスタと照合して、DTF印刷用画像をZIPで一括出力するツールです。
Amazon版（orimake の注文情報管理）と同じ画面構成で、将来 orimake に統合する前提で作っています。

- 公開URL：https://oshikatsu-crypto.github.io/orimake-rakuten-yahoo/
- 統合する開発者向けの説明：[docs/INTEGRATION.md](docs/INTEGRATION.md)

## 個人情報・社内データの扱い

- 注文CSV（お客様の氏名など）は、開いているブラウザの中だけで処理します。どこにも送信・保存しません。
- 商品管理マスタ、Yahoo!旧コード対応表、DTF画像は、このリポジトリには含めていません。各PCのブラウザで最初に1回だけ読み込みます（そのPCのブラウザ内に保存されます）。

## 初回の設定（PC・ブラウザごとに1回）

公開URLを開き、右上の「⚙ 設定」から次の3つを読み込みます。足りないものは、アップロード欄の下に案内が出ます。

| 読み込むもの | 設定の場所 | ファイル |
|---|---|---|
| DTF画像 | 「DTF画像」→「フォルダを取り込む」 | DTF画像が入ったフォルダ（約3,800枚） |
| 商品管理マスタ | 「Excelでまとめて登録・更新したいとき」→「Excelを読み込んで一括更新」 | 商品管理マスタ（.xlsm） |
| Yahoo!旧コード対応表 | 「Yahoo!旧コード対応表」→「対応表CSVを読み込む」 | Yahoo旧コード対応表_候補.csv |

## 毎日の作業

1. 楽天の未出荷CSVと、Yahoo!の注文情報CSV・商品情報CSVを、画面にまとめてドラッグ＆ドロップする（ダウンロード手順はアップロード欄の下にあります）
2. 「ギフト注文一覧」「名入れ・オーダー注文一覧」「画像なし」を確認する
3. 「DTF画像ZIPをダウンロード」を押す

## 主なルール

| 内容 | ルール |
|---|---|
| ファイル名 | `注文日時(YYYYMMDDHHmmss)_画像名_連番.png`。背面は `_背面`、両面は `_前面`・`_背面` の2枚、胸は `_胸`（縮小） |
| サイズ別の画像 | キッズ（100〜150）は `[キッズ]`、4XL以上は `[大]` の画像 |
| 黒T・白T | 画像名の「黒／白」はTシャツの色。インクがTシャツと同じ色の画像は、反対色の画像に自動で差し替える |
| ZIPに入れないもの | 名入れ（`nt-`・商品名に「名入れ」で画像なし）、写真プリント（`pt-`）、無地（`lt-` で商品名に「無地」） |
| ギフト | ラッピング・のし・ギフト包装・ソーシャルギフトの指定がある注文だけ一覧に出す |

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面 |
| `js/core.js` | 業務ロジック（CSVの読み込み、SKU→画像の紐づけ、出力ファイル名）。画面に依存しない |
| `js/image.js` | 画像処理（胸・キッズの縮小、インク色の確認） |
| `js/storage.js` | ブラウザ内の保存 |
| `js/app.js` | 画面の操作と表示 |
| `tests/` | 自動テスト（架空のデータを使用） |
| `docs/INTEGRATION.md` | orimake への統合ガイド |

## テスト

```
node --test tests/
```
